# Open Graph Cal Sans assets

The Open Graph renderer uses the static Regular and Bold Cal Sans v2.001 TTF
instances because Satori does not support WOFF2 and cannot parse the variable
Cal Sans TTF used by the site. These files match `cal-sans@2.0.6` at upstream
commit `3f48161bf97f4e6cb405c41c9945a30c957ada81`.

Source: <https://github.com/calcom/sans/tree/3f48161bf97f4e6cb405c41c9945a30c957ada81/fonts/calsans-static-essentials>
